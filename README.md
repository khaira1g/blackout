# blackout
This is an experiemental Wifi control tool I'm developing in my free time. It's still a WIP. 

## Warning
This tool is for educational and authorized testing purposes only on networks you own or have explicit permission to test. Unauthorized use against networks you do not own is illegal in most places. I am not responsible for an damage caused.

## Requirements
- Linux (im looking to make versions for other operating systems)
- Compatible WiFi adapter that supports monitor mode
- `aircrack-ng` suite installed on your system
- Python 3 installed on your system
